El correo difícil no necesita más IA. Necesita que no te disculpes por existir. ChatGPT, de serie, suaviza. Esta guía lo ata.

## Objetivo en una línea

"Que paguen la factura 2026-114 esta semana", "que el proveedor deje de escribirme", "que no haré el extra sin presupuesto". Si no puedes escribirlo, no hay prompt que valga.

## Prompt

```
Escribe un email en español, tú, 120 palabras máximo.
Contexto: [hechos, fechas, importes]
Relación: [cliente / jefe / proveedor]
Objetivo único: [la línea]
Reglas:
- Asunto de 6 palabras con el hecho (Factura 2026-114 vencida / No seguiré con el extra)
- Sin "espero que estés bien", sin "solo quería", sin "cualquier cosa me dices"
- Una petición, una fecha
- Cierra con nombre. Sin "quedando a tu entera disposición"
```

## Recorte

```
Quita la mitad de las palabras. Si una frase no es hecho o petición, fuera.
```

Si sigue largo, Claude recorta mejor. Si el correo es una ruptura legal, [reclamación con Claude](/guias/claude-carta-reclamacion).

## No uses IA para

Despedir a una persona de tu equipo por chat. Eso es presencial o videollamada, y luego un escrito de HR, no un GPT.
